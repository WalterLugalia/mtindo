# Mtindo

A Flutter fashion discovery and community voting application.

Mtindo allows users to discover fashion products from external retail APIs,
view product details, and vote for products they like. The app uses community
votes to create a "Top Voted" fashion leaderboard.

## Features

### Fashion Feed

- Browse fashion products from external retail APIs
- Display product images, names, brands, and prices
- Pull-to-refresh
- Loading, empty, and error states
- Cached product feed for offline access

### Product Details

- View product image
- View product name and brand
- View price and currency
- View category
- View external product URL
- View current vote count
- Vote for the product

### Authentication

Browsing the app does not require an account.

Authentication is required when voting.

Supported authentication:

- Email/password sign up
- Email/password login
- Logout
- Session persistence
- Session restoration
- Authentication error handling
